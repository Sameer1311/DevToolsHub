# DevToolsHub – All-in-One Developer Toolkit

DevToolsHub puts the small tools developers use every day in one fast, clean web app, so you don't need ten browser tabs.

**Live demo:** https://dev-tools-hub-silk.vercel.app

## Tools
- **JSON formatter** – format and validate JSON
- **Regex tester** – test patterns against sample text
- **Markdown editor** – write Markdown with a live preview
- **Code beautifier** – clean up code with Prettier
- **Color picker** – pick colors and copy HEX / RGB values

## Also includes
- Sign-up and login with NextAuth and MongoDB
- Code editor powered by Ace
- Dark and light mode, responsive layout

## Tech stack
Next.js (App Router) · React · Tailwind CSS · MongoDB + Mongoose · NextAuth · Ace editor · Prettier · Marked · Framer Motion

## Run locally
```bash
git clone https://github.com/Sameer1311/DevToolsHub.git
cd DevToolsHub
npm install
# add your MongoDB URI and NextAuth secret to .env.local
npm run dev
```
